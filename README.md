# Poora Teeka

Nearly half of dog-bite victims in India who start rabies vaccination never finish the
course, and clinics routinely throw away vaccine because an opened vial only lasts a
few hours. Poora Teeka is a dose-completion and vial-logistics tool for anti-rabies
clinics, built for the AWS First Commit hackathon (WeMakeDevs × AWS), September 2026.
